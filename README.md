# Скан — от сканов FARO до плана

Программа в браузере (один файл `index.html`, ничего устанавливать не нужно).

1. **Сканы** — загрузите E57. Сканы FARO `.fls` пересохраняются в E57 файлом `fls_to_e57.bat` (нужен бесплатный CloudCompare 2.12+ с плагином FARO).
2. **Сборка** — «🤖 Автосшивка»: сканы сшиваются сами и сразу уточняются. Линии и углы для плана: «⌇ Линия стены», «／ Линия», «⌖ Угол плана».
3. **План** — «🏠 План по сканам»: стены (в том числе косые), помещения с площадями, двери, окна и подоконники. Выгрузка — DXF и файл проекта для Рулетки.

Работает в Chrome / Edge. Всё хранится на этом устройстве.
